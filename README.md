# Terminal that can kill

by **Solon**

Мод для **Lethal Company** (V81, BepInEx 5.4.21+, HarmonyX) с двумя механиками:

1. **Смертельные двери** — корабельная рампа и большие «терминальные» силовые двери
   на любой луне убивают игроков и/или монстров, стоящих **в проёме** в момент закрытия.
2. **Удалённое управление ловушками** — код в терминале **детонирует** мину и **сводит
   с ума** турель вместо стандартного отключения, с настраиваемым шансом критической
   ошибки. После берсерка турель разворачивает голову на 180°.

Полностью конфигурируется.

> **Мультиплеер:** мод должен стоять и у хоста, и у всех клиентов. Он меняет общие
> правила игры (двери, ловушки), а не даёт одному игроку скрытое преимущество.

## Как это работает (кратко)

### Смертельные двери
- **Корабельная дверь:** постфикс на `HangarShipDoor.Update`; закрытие определяется по
  `doorPower < 1` + состоянию аниматора `"ShipDoorClose"`. Смертельна только на поверхности
  (`shipHasLanded`). Центр зоны — фиксированная мировая координата корабельного проёма
  (корабль всегда в одной точке мира), ось «сквозь дверь» берётся из `outsideDoorPoint`.
- **Терминальная дверь:** постфикс на `TerminalAccessibleObject.SetDoorOpen` ловит переход
  «открыта → закрыта»; крэш выполняется покадрово (`TerminalDoorCrush`) через
  `TerminalDoorCloseSeconds` после начала закрытия.
- **Зона поражения** — тонкая ориентированная «плита» точно в плоскости проёма
  (`DoorwayThickness/Width/Height`), а не сфера: убивает только того, кто **в проёме**.
- **Игроки:** каждый клиент проверяет и убивает только своего локального игрока
  (`KillPlayer` сам синхронизирует смерть). **Монстры:** только хост (владеет ИИ).
- Смерть повторяет смерть от монстра **Barber** (`ClaySurgeonAI`): подброс тела вверх,
  причина `Snipping`, рэгдолл `PlayerDeathAnimationId = 7`.
- Монстры, которые не могут войти в корабль (Ghost Girl, Old Bird, Manticoil, Locust
  и т. п.), исключаются списком `ExcludedEnemies`. «Безопасный период» после посадки —
  `SafeZoneSeconds`.

### Удалённое управление ловушками
- Префикс на `TerminalAccessibleObject.CallFunctionFromTerminal` (метод ввода кода).
- **Мина:** `ExplodeMineServerRpc()` — взрыв вместо отключения; при ошибке — цепная
  детонация соседних мин.
- **Турель:** ванильная связка `SwitchTurretMode(3)` + `EnterBerserkModeServerRpc(...)` —
  берсерк; при ошибке раж продлевается. При выходе из берсерка голова плавно
  разворачивается на 180° (`TurretFlipOnBerserkExit`) — постфикс на `Turret.Update`.
- Всё через уже синхронизированные игрой RPC — **свой NetworkObject не нужен**, меньше
  конфликтов с другими модами.

## Сборка

Нужен **.NET SDK** (8/9) и доступ в NuGet.

```bash
dotnet build LethalDoors.csproj -c Release
```

Результат: `bin/Release/Solon.TerminalThatCanKill.dll`.

`csproj` тянет игровые сборки через NuGet-пакет `LethalCompany.GameLibs.Steam`
(publicized-стабы `Assembly-CSharp`, `Unity.Netcode`). Пакет подключён с
`PrivateAssets="all"` — то есть используется **только при компиляции** и **не попадает**
в собранный мод (файлы игры не распространяются). Версия закреплена под V81
(`81.0.5-ngd.0`).

## Совместимость
- Работает на ванильных и модовых лунах (`LethalLevelLoader`) — двери находятся
  динамически, без хардкода сцен.
- Не создаёт собственных сетевых объектов, опирается на ванильные RPC.
- Если другой мод тоже патчит `CallFunctionFromTerminal` — наш префикс, возвращая `false`,
  подавляет ванильное отключение мин/турелей; при конфликте отключите `EnableRemoteControl`.
